## 1단계 — 일러스트 오기 전까지 (8월)

일러스트가 없어도 할 수 있는 걸 먼저 끝낸다.
그림이 도착하면 **경로만 덮어쓰면** 되도록 이미 만들어져 있다.

### 친구 담당 — 콘텐츠

- [ ] 하루 서사 구체화 (`src/data/scenes.ts` 의 대사·지문)
- [ ] 문항 필터링 — 장면 맥락에 안 맞는 문항 골라내기
      (지금은 아침 기상 장면에 "연애를 안 하는 이유는?" 같은 게 섞인다)
- [ ] 결과 내용 개선 — 지금 결과가 밋밋하다는 피드백이 있었다

### 코드 담당

우선순위 순서다. 위에서부터 한다.

- [ ] **공유 링크 + PNG 썸네일**
      카톡에 링크를 붙였을 때 "나는 가온이래" 가 뜨게 만든다.
      지금 썸네일은 SVG라 카카오톡·페이스북이 못 읽는다.
      **일러스트 없이도 된다** — 그림이 아니라 유형 이름을 넣은
      타이포그래피 카드를 PNG로 생성하면 충분하다.
      → 이게 사람이 늘어나는 유일한 경로라 제일 먼저 한다.

- [ ] **결과 화면 구조**
      친구가 쓴 결과 내용이 들어갈 그릇을 만든다.
      내용과 구조를 분리해둬야 친구가 코드를 안 건드리고 글만 고칠 수 있다.

- [ ] **방문 측정** (Cloudflare Web Analytics, 무료)
      완주율과 공유 클릭률을 잰다.
      이 숫자 없이는 광고를 붙일지 유료화를 할지 판단할 근거가 없다.

- [ ] **문항 태그 구조**
      친구의 필터링 작업을 코드로 받쳐주는 부분.
      장면별로 어떤 문항이 어울리는지 표시할 수 있게 하고,
      태그가 빠진 문항을 `npm run check:questions` 가 잡아내게 한다.

- [ ] **개인정보 처리방침 페이지**
      광고를 붙이려면 필수다. 미리 만들어둔다.

## 4단계 — 수익화

여기서부터는 [수익화 조사](#수익화-요약) 결과를 따른다.

- [ ] 광고 — 슬롯을 `#app` 바깥에 둬야 한다.
      화면 전환마다 다시 그려지면 무효 노출로 계정이 정지된다
- [ ] 유료 심화 리포트 — 개인사업자 등록이 선행돼야 한다
- [ ] AI 기능 — 결과 분석은 16유형을 미리 생성해두면 API 없이 무료.
      DM 분석만 Worker + AI Gateway 경유

### 수익화 요약

조사해보니 심리테스트 사이트의 광고 수익은 **완주 1건당 $0.01~0.05** 다.
반면 유료 리포트는 같은 사용자에게서 수백 배를 만든다.

우리 검사는 35문항을 끝까지 하는 구조라 완주자의 관여도가 높다.
그런 사용자를 광고 1페이지뷰로 환산하는 건 자산 낭비다.

**아직 정해야 할 것 세 가지**

1. 애드센스 계정 명의 — 만 18세 이상이어야 한다
2. 타깃을 고등학생으로 둘지, 20대까지 넓힐지
   — 미성년 대상은 맞춤광고가 막혀서 단가가 바닥이다
3. 개인사업자 등록 의향 — 유료 리포트를 팔려면 필요하다
