## 1단계 — 검사 설계 (지금)

**여기가 막히면 뒤가 전부 막힌다.** 다른 걸 먼저 하지 않는 게 좋다.

담당: 친구 + 그쪽 Claude → [인수인계 문서](HANDOFF.md)

정하는 순서:

1. 무엇을 잴 것인가 (축)
2. 결과를 어떤 모양으로 낼 것인가
3. 시작 질문 — 아바타 재료 + 분기 조건
4. 본 문항
5. 한 사람당 몇 문항
6. 서사를 쓸지, 쓴다면 무엇을 따라갈지

`src/data/` 의 다섯 파일이 차면 검사가 바로 돌아간다.

---

## 2단계 — 결과와 공유 (일러스트 전에 가능)

문항이 정해지면 바로 붙일 수 있다. 일러스트를 기다릴 필요가 없다.

1. **결과 화면** — 친구가 쓴 내용이 들어갈 그릇
2. **PNG 공유 썸네일** — 지금 SVG라 카톡에서 안 뜬다.
   그림이 아니라 타이포그래피 카드로도 충분하다
3. **결과별 공유 링크** — 링크 받은 사람이 보고 나도 하게
4. **방문 측정** — 완주율. 이 숫자 없이는 수익화 판단을 못 한다
5. **개인정보 처리방침** — 광고의 전제조건

공유가 **사람이 늘어나는 유일한 경로**다. 나머지를 다 해도 공유가 안 되면 아무도 안 온다.

---

## 3단계 — 일러스트 (9월)

- 아바타 조각 — 조합으로 만들면 장수가 확 준다 (머리 3 × 표정 3 = 6장으로 9가지)
- 장면 배경
- 좋아하는 상대 그림 (성별·특징별)
- 공유 썸네일
- **미감 확정** — 지금은 무채색 뼈대. `src/styles/app.css` 상단 토큰만 바꾸면 전체가 따라온다

그림은 정해진 경로에 같은 이름으로 덮어쓰면 코드 수정 없이 반영된다.

---

## 4단계 — 공개

- 도메인 구입 (연 1.5~2만 원). 그 전까지는 지금 주소로 충분하다
- 검색 등록 (구글 서치콘솔 · 네이버 서치어드바이저)
- 친구들에게 먼저 돌려보고 완주율 확인

---

## 5단계 — 수익화

- 광고 — 슬롯을 `#app` 바깥에 둬야 한다.
  화면 전환마다 다시 그려지면 무효 노출로 계정이 정지된다
- 유료 심화 리포트 — 개인사업자 등록이 선행
- AI 기능 — 결과 분석은 미리 생성해두면 API 없이 무료.
  DM 분석만 Worker + AI Gateway 경유

### 수익화 요약

조사해보니 심리테스트 사이트의 광고 수익은 **완주 1건당 $0.01~0.05** 다.
반면 유료 리포트는 같은 사용자에게서 수백 배를 만든다.

끝까지 답한 사람은 관여도가 높다. 그런 사용자를 광고 1페이지뷰로 환산하는 건
자산 낭비다.

**아직 사람이 정해야 하는 것 세 가지**

1. 애드센스 계정 명의 — 만 18세 이상이어야 한다
2. 타깃을 고등학생으로 둘지, 20대까지 넓힐지
   — 미성년 대상은 맞춤광고가 막혀서 단가가 바닥이다
3. 개인사업자 등록 의향 — 유료 리포트를 팔려면 필요하다
