# 구조 설명

## 왜 새로 짰나

v1(`index.html`)은 7,500줄짜리 HTML 파일 하나였다. 돌아가긴 했지만 세 가지가 막혀 있었다.

1. **페이지가 하나뿐** — 공유 링크에 유형별 썸네일을 띄울 수 없고, 검색엔진에 걸릴 페이지도 하나였다
2. **문항 100개** — 돌려본 사람들이 길다고 했다
3. **한 파일** — 둘이 같이 고치면 충돌이 난다

v2는 이 셋을 구조로 푼다. 반대로 v1에서 잘 돌아가던 것(문항 데이터, 채점 정규화)은 그대로 가져왔다.

## 폴더

```
src/
  data/
    scenes.ts          하루 서사 — 대사·지문·문항 자리
    questions/*.json   문항 364개 (v1에서 이전, 뱅크별로 분리)
    intro.json         기본 질문 7개
    types.json         16개 유형
    axes.json          축 정의
  engine/
    types.ts           타입 정의 전부
    select.ts          문항 뽑는 규칙        ← 자주 바뀔 곳
    score.ts           채점                  ← 건드리지 말 것
  scripts/
    player.ts          화면 진행 (탭 → 다음)
  pages/
    index.astro        랜딩
    play.astro         검사
    type/[code].astro  유형 16개 (자동 생성)
  layouts/Base.astro   공통 head·OG 태그
  styles/app.css       스타일 전부
public/art/            일러스트 자리 (제미나이 생성물로 교체)
tools/                 데이터 이전·검사 스크립트
```

## 서사와 문항이 분리돼 있다

이게 v2의 핵심이다.

`scenes.ts` 는 **이야기만** 갖는다. 어떤 문항이 나올지는 "이 뱅크에서 하나" 라고만 적는다.

```ts
{ kind: 'question', slot: { from: 'ch3-crush' } }
```

`select.ts` 가 실행 시점에 실제 문항을 채운다. 그래서:

- 문항 내용을 바꿔도 → 이야기는 그대로
- 이야기를 바꿔도 → 채점은 그대로
- 뽑는 규칙을 바꿔도 → 위 둘 다 그대로

특정 문항을 꼭 그 자리에 넣고 싶으면 `slot: { from: 'ch3-crush', id: 'c3-05' }` 처럼 고정하면 된다.

## 채점은 왜 그렇게 생겼나

`score.ts` 의 정규화는 v1에서 검증된 것이라 **바꾸지 않는 게 좋다.**

점수를 그냥 더하면 "그 사람에게 어떤 문항이 뽑혔는지"가 결과에 섞여 들어간다.
사람마다 문항이 달라지는 구조에서는 치명적이다. 그래서 이렇게 한다.

1. 그 세트를 **무작위로 찍었을 때의 기댓값**을 구한다 → 이게 판정선
2. 실제 점수가 거기서 얼마나 벗어났는지 본다
3. 그 방향으로 갈 수 있었던 **최대 이탈폭**으로 나눈다

세트가 어느 쪽으로 치우쳐 있든 판정선이 자동으로 가운데 온다.

## 문항을 손봤으면 반드시 이걸 돌린다

```bash
npm run check:questions
```

자기소개 조합 4,800가지를 전부 돌려서 확인한다.

- 문항 자리 35개가 전부 채워지는지 (조건 문항 때문에 뱅크가 마르면 조용히 빠진다)
- 같은 문항이 두 번 안 나오는지
- 16개 유형에 다 도달할 수 있는지

## 알고 있는 한계

- **공유 썸네일이 SVG다.** 카카오톡·페이스북은 SVG를 못 읽는다. 공개 전에 PNG로 바꿔야 한다 (`docs/ART-MANIFEST.md`)
- **결과 화면이 임시다.** 유형 코드와 축 게이지만 나온다. 결과 내용은 따로 작업 중
- **문항 364개가 전부 번들에 들어간다** (gzip 50KB). 실제로 쓰는 건 35개뿐이라 나중에 나눠 실을 수 있다. 지금은 문제 될 규모가 아니다
- **v1 `index.html` 이 아직 저장소에 있다.** GitHub Pages 데모를 살려두려고 남겼다. Cloudflare로 옮기고 나면 지우면 된다
