# 그림 규격 — 생성 시작 전에 반드시 읽을 것

**한 달 안에 다 만들어야 하므로, 규격이 어긋나면 그게 제일 큰 손해다.**
부품 50장을 뽑고 나서 기준점이 안 맞는 걸 알면 전부 다시 그려야 한다.
**처음 3~5장 뽑자마자 확인**하고 시작하라.

---

## 1. 규격

| | |
| --- | --- |
| 캔버스 | **1024 × 1536** (2:3 세로) |
| 배경 | **완전 투명** |
| 형식 | WebP 권장 (PNG도 가능) |
| 용량 | 장당 **250KB 이하** |
| 위치 | `public/art/parts/` |

1024×1536은 AI 이미지 생성의 세로 기본 규격이라 그대로 쓸 수 있다.

## 2. 기준선 — 이게 제일 중요하다

부품을 겹쳐서 한 사람을 만들기 때문에, **모든 부품이 같은 위치에 그려져야 한다.**
머리 부품과 몸 부품의 목 위치가 다르면 겹쳤을 때 어긋난다.

| 기준 | y좌표 (1536 기준) |
| --- | --- |
| 중심선 | x = **512** |
| 정수리 | 210 |
| 눈높이 | 400 |
| 턱끝 | 530 |
| 어깨 | 640 |
| 허리 | 940 |
| 무릎 | 1230 |
| 발바닥 | 1460 |

**정렬 가이드 이미지**: `public/art/_guide.svg`
([배포본에서 보기](https://crush-lab.kangchiteacher123.workers.dev/art/_guide.svg))

이 이미지를 **ChatGPT에 첨부**하고 "이 가이드의 비율과 위치에 맞춰서" 라고 지시하면
부품들이 같은 자리에 나온다. 매 생성마다 첨부하는 게 좋다.

가이드를 고치려면 `tools/make-art-guide.mjs` 를 수정하고 `npm run art:guide`.

## 3. 투명 배경 — 가장 흔한 함정

**ChatGPT 이미지 생성은 투명 배경을 제대로 안 준다.** 흰 배경이나 체크무늬를 흉내낸
그림이 나오는 경우가 많다. 그대로 쓰면 아래 부품을 가려서 조립이 안 된다.

권장 방법:

1. **단색 배경으로 뽑는다.** 프롬프트에 `배경은 완전한 단색 마젠타 #FF00FF, 그림자 없음`
   처럼 지정한다. 그림에 안 쓰이는 색이어야 한다
2. 배경 제거 도구로 그 색을 지운다 (remove.bg, Photopea 등 무료)
3. `npm run check:art` 로 투명 여부를 확인한다 — 불투명하면 잡아준다

## 4. 일관성 유지

부품마다 화풍이 다르면 겹쳤을 때 한 사람으로 안 보인다.

- **같은 대화 스레드에서 이어서 생성한다.** 새 대화를 시작하면 화풍이 달라진다
- **먼저 스타일 앵커 한 장을 만든다.** 전신 캐릭터 완성본 1장을 뽑아 마음에 들 때까지
  다듬고, 그 뒤 모든 부품 생성에 **그 이미지를 첨부**해서 "같은 화풍으로" 지시한다
- 두 사람(자기·상대)이 같은 세계에 있어야 하므로 앵커는 하나로 통일한다

## 5. 프롬프트 구조

프롬프트 = **스타일 앵커** + **부품 지시** + **규격 지시**

```
[스타일 앵커]
첨부한 이미지와 완전히 같은 화풍·선 굵기·채색으로.
한국 고등학생, 부드러운 애니메이션풍, 채도 낮은 파스텔, 얇은 선.

[부품 지시]
어깨까지 오는 긴 생머리만 그려라. 얼굴·몸·옷은 그리지 말 것.

[규격 지시]
세로 1024×1536. 첨부한 가이드의 기준선에 맞춰
정수리는 y=210, 턱끝은 y=530, 중심선은 x=512에 오도록.
배경은 완전한 단색 마젠타(#FF00FF), 그림자·테두리 없음.
```

**부품 하나씩** 뽑는다. 한 번에 여러 개를 요구하면 기준이 흐트러진다.

## 6. 무엇부터 그릴 것인가

한 달 안에 끝내려면 **막히는 것부터** 그린다.

| 순서 | 무엇 | 왜 먼저인가 |
| --- | --- | --- |
| 1 | **스타일 앵커 1장** | 이게 없으면 나머지 전부가 제각각이 된다 |
| 2 | **체형(body) 1~3종** | 모든 조합의 바탕. 이게 맞아야 나머지를 맞춘다 |
| 3 | **머리(hair) 3~5종** | 아바타 변화가 제일 눈에 띄는 부분 |
| 4 | **얼굴(face) 3~4종** | 표정으로 성격이 드러난다 |
| 5 | 교복·소품 | 있으면 좋고 없어도 돌아간다 |
| 6 | 상대 캐릭터 부품 | 자기 부품을 재활용할 수 있으면 크게 준다 |
| 7 | 장면 배경 | 장면 수가 정해진 뒤에 |
| 8 | 공유 썸네일 | 마지막. 타이포그래피만으로도 되므로 급하지 않다 |

**2~4번을 3장쯤 뽑았을 때 반드시 확인하고 넘어간다.** 아래 참고.

## 7. 확인하는 법

### 넣기

1. 이미지를 `public/art/parts/` 에 넣는다
2. `src/data/parts.ts` 에 등록한다

```ts
{ id:'hair-long', slot:'hair', z:3, src:'/art/parts/hair-long.webp',
  label:'긴 머리', when:{ hair:'long' } },
```

### 검사

```bash
npm run check:art
```

- 파일이 실제로 있는지
- 캔버스 비율이 규격과 맞는지
- **배경이 투명한지**
- 용량이 큰지
- 슬롯마다 기본값(조건 없는 부품)이 있는지

### 눈으로 확인

```bash
npm run dev
```

→ <http://localhost:4321/art>

부품을 겹친 조합과 낱개를 한 화면에서 본다.
**"기준선 겹쳐 보기"** 를 켜면 기준선이 오버레이된다.
겹쳤을 때 목·어깨가 어긋나면 그 부품의 기준이 안 맞는 것이다.

## 8. 조합으로 장수를 줄인다

경우의 수만큼 완성본을 그리면 감당이 안 된다.

| | 완성본으로 그리면 | 부품으로 나누면 |
| --- | --- | --- |
| 머리 4 × 체형 3 × 얼굴 4 | **48장** | **11장** |
| 여기에 상대 캐릭터까지 | 2,304장 | 22장 |

슬롯을 늘리기보다 **슬롯당 종류를 늘리는 쪽**이 효율이 좋다.

## 9. z 순서

겹치는 순서다. 낮을수록 뒤.

```
0  body     체형
1  uniform  교복
3  hair     머리
4  face     얼굴
5  extra    안경·소품
```

같은 슬롯의 부품들은 같은 z 를 쓴다. `check:art` 가 다르면 알려준다.
머리를 얼굴보다 앞에 둘지 뒤에 둘지는 앞머리 유무에 따라 정하면 된다.
